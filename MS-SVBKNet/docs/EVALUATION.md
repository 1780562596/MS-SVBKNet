# 数据与评测协议

## 数据划分

GoPro 使用 22 个官方训练场景中的 18 个训练场景和 4 个验证场景，种子 3407；官方测试为 11 个场景、1,111 对图像。完整配置校验训练/验证各自场景数和总配对数。索引工具默认选 4 个验证场景，也可显式传入 `--val-scenes 4`；`--val-fraction` 为其他实验保留。

划分工具从排序后的场景路径生成确定性本地划分。论文的原始 CSV 尚未提供，因此不能将生成的清单直接当作论文原始清单。运行前执行数据审计。

数据加载检查配对文件、尺寸、重复输入及跨分区共享路径。启用场景检查时，审计覆盖 train/val、train/test、val/test。场景身份通过路径中 blur/sharp 目录的上级推断；不规范目录或跨分区重复拷贝可能无法据此识别相同源场景。

GS-Blur 必须按原始重建场景分为 2726/341/341。同一清晰参考对应的不同模糊变体不能跨分区。现有 CSV 支持一对多配对，但不包含独立的原始场景 ID 字段；GS-Blur 示例未自动启用场景检查，须提供源场景分组清单并人工核对。配对工具不能替代源场景划分。

## 评测口径

正式配置默认 `metric_protocol=gopro_matlab`：

- 完整 RGB，crop border 为 0；
- 输出与目标先量化到 8 位 PNG 网格；
- 每幅图分别计算 PSNR、SSIM，然后取平均；
- SSIM 使用 11×11 Gaussian 窗，sigma=1.5，valid 区域；
- LPIPS 为官方 v0.1 校准模型，VGG16 骨干，输入范围 [-1,1]，同样使用量化后的图像；
- 默认完整图像推理，分块需单独注明。

论文明确采用 RGB、官方 LPIPS v0.1/VGG16 和完整测试图像；blur/blur_gamma 的最终选择、量化顺序及 SSIM 实现细节仍应与正式实验记录核对。当前仓库明确保存这些配置，避免混合比较。

`float_rgb` 使用浮点输出；smoke 配置采用这一模式并关闭 LPIPS。不能将其结果与量化协议直接等同。

## YOLO

论文使用同一个冻结 YOLOv8n、COCO 权重，类别 ID 为 2/3/5/7，图像尺寸 640；可视化置信度 0.25，验证候选框阈值 0.001，NMS IoU 0.70。工具显式传入并记录这些参数。

三组输入目录必须具有相同的相对文件路径。带标注评测要求每组都提供 YAML，并使用相同帧和共享真实标注。工具不能验证标注内容是否对应同一个物理场景；发布时需附数据说明及 Ultralytics 版本。无标注结果只含检测数量和置信度，不能用来推算 mAP。
