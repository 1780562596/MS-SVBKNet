# 版本兼容说明

当前版本沿用压缩包中的模型主体和正式 LPIPS v0.1/VGG16 后端，并更新数据划分约束、场景审计和 YOLO 对比接口。

- Python 包名为 `ms-svbknet`，导入路径仍为 `ms_svbknet`。
- 实验环境记录文件名改为 `experiment_manifest.json`。
- GoPro 默认划分改为 18 个训练场景、4 个验证场景，默认选择种子 3407。
- 完整 GoPro YAML 新增训练/验证各自场景数约束。
- 场景泄漏检查覆盖所有提供的分区。
- YOLO 对比支持清晰参考分支，显式记录图像尺寸与检测/验证阈值。

新增数据配置会改变严格训练签名。旧检查点与当前网络结构匹配时仍可用于评估；严格续训必须沿用检查点记录的原始训练配置，不能忽略签名错误。

旧版的 VGG19 特征距离不属于正式指标，不能与标准 LPIPS v0.1/VGG16 混报。
