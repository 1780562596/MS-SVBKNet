# MS-SVBKNet 实现说明

本文件说明论文代码的计算流程、配置与模块对应关系。默认参数以 `configs/full.yaml` 为准；GS-Blur 使用独立数据配置。

## 模型与代码

| 组件 | 文件 | 实现 |
|---|---|---|
| 生成器 | `ms_svbknet/models/generator.py` | 编码器、10 个改进残差块、解码器、全局残差和 Tanh |
| 改进残差块 | `ms_svbknet/models/blocks.py` | 三层 3×3 卷积，无 BN，分层 Dropout |
| MDRM | `ms_svbknet/models/mdrm.py` | 三尺度特征对齐后拼接，1×1 卷积融合 |
| SVBKM | `ms_svbknet/models/svbkm.py` | 两层 3×3 + 一层 1×1 的权重预测网络，基核维度 Softmax |
| 基核字典 | 同上 | 16 个 15×15 基核，空间 Softmax 保证非负且总和为 1 |
| CRCM | `ms_svbknet/losses.py` | 由局部重模糊误差得到可靠性权重，停止权重梯度 |
| 判别器 | `ms_svbknet/models/discriminator.py` | 六层改进 PatchGAN，无 BN，全局均值聚合 |

基核按线性运动核初始化，方向为 `180*i/16` 度，长度从 1 到 14 像素。局部核为 `K(x,y)=sum_i W_i(x,y)K_i`。重模糊采用逐基核卷积后按像素混合的等价计算，避免显式展开整幅图像的所有局部核。

## 联合损失

`L = L_pixel + 0.10*L_frequency + 0.001*L_adversarial + lambda_t*L_credible`。

- 像素损失：图像空间 L1。
- 频域损失：正交归一化 RFFT 的复频谱差的幅值均值。
- 生成器对抗损失：`-mean(D(restored))`。
- 局部误差：`E=mean_channel(abs(reblurred-blurred))`。
- 可靠性：`R=exp(-8*E)`；损失中默认对 R 停止梯度。
- 可信损失：`mean(stopgrad(R)*abs(reblurred-blurred))`。
- 动态权重：首次为 0.10；后续为 `clip(0.10*L_initial/EMA(L_t), 0.10, 3.00)`，EMA 系数 0.98。
- 判别器：WGAN-GP，梯度惩罚系数 10。

计算使用网络内部的 RGB `[-1,1]` 张量。实现还保留 hinge、LSGAN 等可配置选项；这些选项不属于默认实验设置。

## 训练配置

| 参数 | 默认值 |
|---|---|
| 随机种子 | 3407 |
| 裁剪尺寸 | 256×256 |
| 训练轮数 / batch size | 300 / 2 |
| 生成器 / 判别器学习率 | 5e-5 / 5e-5 |
| MDRM 与 SVBKM 优化器学习率 | 1e-4 |
| Adam betas | (0, 0.9) |
| AMP / 梯度范数上限 | 开启 / 5.0 |
| 生成器基础通道 / MDRM 输出通道 | 50 / 64 |
| 残差块 Dropout | 前 3 块 0，中间 4 块 0.15，后 3 块 0.25 |
| 最佳检查点选择 | 验证集 PSNR |

水平翻转、垂直翻转各以 0.5 概率执行，旋转从 0/90/180/270 度选取。模糊与清晰图像同步变换。

## 配置与模型文件的对应

当前代码默认 `model.fuse_mdrm_to_generator=true`，将 MDRM 特征投影后加到生成器瓶颈。论文的整体图以并行分支展示生成器与 MDRM，未明确标注该融合连接。论文也未逐项给出通道数、Dropout 分段边界，以及残差相加后的激活细节。本次整理保留现有网络实现；提供最终训练配置与权重后，应逐项核对这些结构细节。不要仅凭参数总量相近就认定架构完全相同。

模型指纹用于防止错误权重加载，训练签名用于严格续训。新增 GoPro 场景数约束会改变训练签名：原始配置的检查点可以用匹配的模型配置推理，但不能将旧训练状态直接作为本版本新划分设置的严格续训。
